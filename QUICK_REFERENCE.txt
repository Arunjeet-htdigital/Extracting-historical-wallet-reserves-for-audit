🐛 COMMON ISSUES

  "API Keys Not Configured"
  → Click ⚙️ Set API Keys, enter them

  "No XLSX files found"
  → Check files are .xlsx (not .xls)
  → Check they're in selected folder

  "Invalid date"
  → Use format YYYY-MM-DD (e.g., 2024-12-05)

  "Takes a long time"
  → Normal! 5-30 sec per wallet is expected
