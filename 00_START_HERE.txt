## 🔨 THE BUILD PROCESS (What Happens)

When you run `BUILD.bat`:

```
1. pip install dependencies
   ↓
2. PyInstaller converts Python → .exe
   ↓
3. Bundles everything into single file:
   - Python runtime
   - pandas, openpyxl, requests libraries
   - Your scripts (solana_alchemy.py, eth_alchemy.py)
   - app_main.py (the GUI)
   ↓
4. Creates: dist/CryptoAnalyzer.exe (~180 MB)
```

Result: **One file that works on any Windows without Python!**

## 🐛 TROUBLESHOOTING

### "Python not found"
→ Install from https://www.python.org/downloads/
→ Check "Add to PATH" during install
→ Restart Command Prompt

### "BUILD.bat failed"
→ Run VERIFY.bat first
→ Make sure all .py files are in same folder
→ Delete `build/` and `dist/` folders, try again

### ".exe too small" (~50 MB or less)
→ Something didn't bundle correctly
→ Delete build files, rebuild

### "ImportError" when running .exe
→ Solana_alchemy.py or eth_alchemy.py missing
→ Make sure they're in the folder when building

### Accountant says ".exe won't run"
→ Check: Windows 10 or 11?
→ Check: Antivirus not blocking?
→ Try: Run as Administrator
→ Have them get latest Windows updates
